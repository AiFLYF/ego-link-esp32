# 测试计划（TEST_PLAN）

> 对象：`docs/test/UI_INVENTORY.md` 里 112 个元素 + 8 个页面状态。
> 维度：功能 / 输入校验 / 异常 / 交互 / 响应式 / 显示 / 可访问性 / 控制台 / 性能。
> 每个用例写明编号、前置条件、步骤、预期结果。执行结果记在 `TEST_REPORT.md`。
>
> 环境约定：服务端跑在 `127.0.0.1:8090`（独立数据目录），假板子用
> `tools/fake_board.py`；浏览器用系统 Chrome（playwright-core，headless）。
> 三档视口：1440×900 / 768×1024 / 375×812。两套主题：light（默认）/ dark。
