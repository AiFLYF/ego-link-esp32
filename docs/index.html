01 · Data Loop

一条真实数据的闭环旅程

每一帧都是板子上真实传感器读出的 g 值 —— 下面两段就是抓包级别的真实载荷。

board ⇄ server ⇄ dashboard · 拖拽可旋转
→① 采集

IMU 采样

SC7A20 三轴读数（WHO_AM_I=0x11 自动识别），换算为 g 并做死区滤波。

→② 上行

POST /api/telemetry

esp_http_client 每 500ms 一帧；断网无限重试，恢复即续传。

→③ 分析

服务器 AI

8s 滑动窗口：倾角八方向、峰值计步、方差判晃动 → 活动标签。

→④ 回屏

响应即下行

activity + AI 回复随响应返回，UTF-8 安全截断后渲染上屏。

→⑤ 旁观

SSE 仪表盘

浏览器 GET /：姿态球、|a| 曲线、事件流实时推送，零刷新。

上行 · board → server（500ms 一帧）
telemetry.json
{ "x": 0.02, "y": -0.98, "z": 0.11,
  "source": "sc7a20", "ask": 0 }
// 按下 BOOT 键 → ask:1, 附提问文本
// 服务器回 {activity, reply} 供屏显
下行 · server → board（同一次请求的响应）
response.json
{ "ok": true,
  "activity": "步行 · 峰值 4 次/8s",
  "reply": "检测到节律性冲击，像步行。" }
// 未接大模型时 reply 为规则引擎真实摘要
// 配 RW1_LLM_API_KEY 自动升级成真 LLM
02 · Highlights

六个值得看的工程决定

零依赖服务器

Python 标准库全家桶

ThreadingHTTPServer + SSE，不装一个 pip 包就有接收、存储、查询、推送四件套。拿到任何一台电脑 python server.py 即跑。

可升级的 AI

规则先行，大模型即插

倾斜/计步/晃动/疑似跌落由滑动窗口规则引擎判定（8s 窗口、阈值可调）；配三个环境变量就换成任意 OpenAI 兼容端点生成回复。

显示工程

104KB 字体子集治好乱码

LVGL 自带 CJK 演示字体缺字严重。gen_font.py 扫描源码+服务器文案，用 fontTools 从本机字体裁子集，tiny_ttf 运行时渲染 —— 屏显中文一个方块都没有。

网络鲁棒

断网是常态，恢复是自动

WiFi 掉线事件驱动重连：前 8 次每 2s、之后每 15s 无限重试；HTTP 失败静默退避。路由器恢复，板子两秒内自己回来，不用碰烧录线。

协议细节

响应即通道，不另开连接

AI 回复搭载在遥测 POST 的响应体返回（HTTP/1.0 兼容坑已填：ON_DATA 累积器读 body），板端一条连接完成双向通信。

隐私设计

凭据永远不进 git

Kconfig 默认值是占位符，真实 WiFi/密码/IP 只存本地 sdkconfig（gitignored）；系统字体产物同样排除 —— clone 即安全，配置走 menuconfig。

03 · Quickstart

四步跑通全流程

需要：一块 ESP32-S3 系开发板（本工程按 S3-EYE 的 240×240 屏写）、ESP-IDF v5.4.x、任意 Python 3.10+。

1

生成中文字体子集（从你本机字体裁，版权安全）

bash
python tools/gen_font.py
2

配置你的 WiFi 与电脑 IP（存在本地 sdkconfig，不会被提交）

bash
cd device
idf.py -D SDKCONFIG_DEFAULTS=sdkconfig.bsp.esp32_s3_eye menuconfig
3

编译烧录（S3-EYE 默认 COM10，按设备管理器改）

bat
cd ..   &   build_device.bat
flash_device.bat COM10 30
4

启动服务器，打开仪表盘，晃一晃板子

bash
python server\server.py
# 浏览器 http://localhost:8000/ ; 板子屏幕 2s 内同步出活动标签
