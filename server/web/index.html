设备与画面

板子是 HTTP 客户端，没有自己的服务端，所以画面由板子推上来、网页从这里取。

摄像头

（板子离线 / 摄像头自检没过时不会有画面）
实时画面是板子推上来的，帧率由板子决定（在上面选）。 实测上限约 2 帧/秒：一帧要等帧 + 开一条 TCP + POST 27KB。 分辨率由传感器固定为 1280x720（OV3660 的 JPEG 只有这一档）。 关掉可省 WiFi 带宽。

板子管理

改完通过「下一帧遥测的响应」下发到板子并写入 NVS；空着 = 不改那一项。

板子设置

改 WiFi 会先试连、连上了才保存（最多 8 秒）—— 密码填错不会把板子弄失联。 上报周期就是「灵敏度」：50ms=20Hz（最跟手）/ 100ms=10Hz / 500ms=2Hz（默认）。 越小越跟手，但 WiFi 压力越大；50ms 已接近单次往返的量级，跑不到也正常。
